# 📊 Nutrition Tracker Pro - v1.0

**Una aplicación web profesional para rastreo nutricional en tiempo real con análisis avanzado, gráficos interactivos y gestión de datos completamente offline.**

## ✨ Características

- ✅ **Rastreo de comidas en tiempo real** - Desayuno, comida, snack, cena
- ✅ **Cálculo automático de macros** - Proteína, carbohidratos, grasas
- ✅ **4 gráficos interactivos** - Peso, calorías, proteína, macros
- ✅ **Estadísticas detalladas** - Semanales, promedio general, mejor día
- ✅ **Creación de productos** - Añade productos personalizados fácilmente
- ✅ **Configuración personalizable** - Pesos, objetivos, rangos nutricionales
- ✅ **Export/Import** - JSON y CSV para respaldo
- ✅ **Modo Offline (PWA)** - Service Worker + cache-first
- ✅ **100% privado** - Datos locales en tu dispositivo, sin servidores
- ✅ **Responsive** - Móvil, tablet, desktop

## 📱 Interfaz - 5 Tabs Principales

| Tab | Descripción |
|-----|-------------|
| 🏠 **Hoy** | Registro diario de comidas + resumen real-time |
| 🍽️ **Productos** | Base de datos de alimentos con búsqueda |
| 📊 **Gráficos** | Visualización de peso, calorías, proteína |
| 📈 **Estadísticas** | Análisis semanales y progresión |
| ⚙️ **Configuración** | Personalización + Export/Import |

---

## 🔐 Privacidad & Datos

- **100% Local** - No hay servidores, no hay datos enviados
- **Cifrado de búsqueda** - Solo caché local de productos
- **Backup Manual** - Descargar datos cuando quieras
- **Completamente Offline** - Funciona sin internet

---

## 🛠️ Tecnología

- **Frontend:** Vanilla JavaScript ES6+ + Tailwind CSS
- **Gráficos:** Chart.js 3.9.1
- **PWA:** Service Worker + manifest.json
- **Almacenamiento:** localStorage + IndexedDB

---

## 💡 Cómo Funciona

1. **Registro de comidas** - Busca productos por nombre o crea customizados
2. **Cálculo automático** - Las macros se calculan según la cantidad
3. **Visualización** - 4 gráficos muestran tu progresión
4. **Análisis** - Estadísticas automáticas de tu semana
5. **Backup** - Descarga tus datos en cualquier momento
